# Alfred UI System

A complete React + TypeScript + Vite implementation of the four-screen Alfred interface:

- Home
- Inbox
- Chat
- Profile
- Shared bottom navigation
- Alfred avatar
- Icon tile system
- Cards, pills, buttons, chips, status tags, and typography tokens

## Run

```bash
npm install
npm run dev
```

## Main files

- `src/App.tsx`
- `src/styles.css`
- `src/components/*`
- `src/pages/*`

The mobile UI is responsive. On screens below 500px it fills the viewport.
