# Alfred · 给设计师的 Brief

## 我们要什么

为忙碌的首席助理做一面「打开就能快速处理」的手机界面：一天只打开几次，三秒内知道该干什么。底部保留 5 个 Tab（Today / Inbox / 中间 Capture / Ask / You）。不要做成数据仪表盘，不要堆 KPI 和密密麻麻的卡片墙。

## 风格

主旋律是**纸白 + 墨黑**的克制编辑感（浅奶白纸底、深墨文字），辅以一点靛蓝强调和陶土色警示即可，整体偏安静杂志，不走暗黑科技、不走紫渐变 SaaS。视觉上**突出管家元素**——Alfred 这个管家形象是品牌与情绪锚点，温暖得体、不卖萌、不吵；信息仍以事务为主，管家点缀而不是抢戏。

## Avatar 动画要做什么

管家会出现在底部中间按钮，以及 Today / Ask 等关键位置。请设计一组可读的小情绪：平静待机、专注、思考（Ask 加载时）、成功、出错、偶尔休息；中间钮点击要有短暂「在听」反馈。动作宜小、短、清楚，让人一眼感到「他在帮我」，而不是大型特效秀。当前 App 里还是立绘+轻微呼吸；你先出关键表情与落点故事板；若同时接动效，再交付 Lottie。

## 请交付

- Figma 链接（可评论）：建议分页 Tokens / 现况 / 改版 / Handoff
- 主屏改版（含：空态、加载、1 条内容、10+ 条、错误）
- 管家 Avatar：落点尺寸 + 上述情绪关键帧 + 中间钮点击流程
- Dev handoff 标注（字号、色、间距、组件状态）
- 一页说明：改了什么、为什么更适合「快速处理」
